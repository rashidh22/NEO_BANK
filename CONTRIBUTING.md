# Contributing

- Link changes to an approved requirement or decision; retain BNK-FR / BNK-AI traceability where applicable.
- Keep all financial flows simulated and use synthetic test data.
- Do not turn TBD product rules into defaults without a recorded decision.
- Submit a pull request with purpose, scope, risk, test evidence and operational impact.
- Require review from the owning domain; security-sensitive changes need security review.
- API/event changes must include compatibility and migration notes.
- Never commit secrets, real personal data or credentials.
